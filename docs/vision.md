# MeepleGo  
## A Personal Board Game Journal, Not a Ranking Machine

---

## 1. What MeepleGo Is

MeepleGo is a **personal reflection layer** for board gaming.

It helps players:
- remember what they’ve played,
- understand how their tastes evolve,
- resurface forgotten favorites,
- and notice patterns that only appear over time.

MeepleGo is not a recommendation engine chasing global consensus.  
It is a **mirror**, not a megaphone.

If BoardGameGeek is the encyclopedia, MeepleGo is the margin notes.

---

## 2. What MeepleGo Is Not

MeepleGo is explicitly **not**:

- a clone of BoardGameGeek
- a “hotness” leaderboard
- a sales chart
- a popularity contest
- a site that pressures users to rate hundreds of games to unlock value

Global rankings, trending lists, and awards may exist—but only as **context**, never as the point.

MeepleGo does not ask: *“What does everyone like?”*  
It asks: *“What does this player like—and how is that changing?”*

---

## 3. The Core Philosophy

> **Personal data should pay off immediately.**

Every action a user takes—rating a game, logging a play, revisiting a title—should create visible value right away.

No “empty dashboards.”  
No “come back when you’ve done more.”  
No dead ends.

If a user has logged **one game**, MeepleGo should already be interesting.

---

## 4. The Three User Phases

MeepleGo is intentionally phase-aware.  
Not all users should see the same experience.

### Phase 1: New User  
**Goal:** Immediate orientation and trust

- The interface is light, welcoming, and non-demanding
- Focus is on:
  - Quick Actions
  - Gentle guidance
  - Clear explanation of what MeepleGo becomes
- No overwhelming stats
- No “power user” features
- No pressure to import or bulk-rate

The site should feel usable within **60 seconds**.

---

### Phase 2: Returning User  
**Goal:** Pattern recognition

- Personal data comes first:
  - Highest Ranked by You
  - Sleeper Hits
  - Hot Takes
- Community context appears **after** personal context
- The homepage begins to feel *tailored*, not generic
- The user starts seeing:
  - surprises
  - rediscoveries
  - contradictions in their own tastes

This is where MeepleGo becomes sticky.

---

### Phase 3: Power User  
**Goal:** Reflection and synthesis

- Long-term patterns emerge:
  - Games revisited
  - Shifts in taste over years
  - Play frequency vs. affection
- Awards, trends, and meta views exist—but as **analysis tools**, not trophies
- The experience respects expertise without turning competitive

Power users are not louder users—they are **deeper** users.

---

## 5. Personal Before Communal (Always)

When both personal and communal data exist, MeepleGo follows this rule:

> **Your data comes first. The world comes second.**

Examples:
- “Your Hidden Gems” appears before “Trending in the Community”
- “Your Revisited Games” matters more than “Most Played”
- Community sections never crowd out personal ones

Community data exists to **contextualize**, not validate.

---

## 6. No Empty Sections, No Guilt-Driven CTAs

MeepleGo avoids:
- “Coming soon”
- “You haven’t done X yet”
- “Rate more games to unlock…”

If there’s nothing meaningful to show, the section doesn’t render.

When guidance is needed, it is:
- editorial
- friendly
- optional
- non-judgmental

MeepleGo never scolds the user for having a life.

---

## 7. Images Are Enhancements, Not Gatekeepers

Missing data should never break discovery.

- Games without images still appear
- Placeholders are acceptable
- Visual polish must not suppress content

A remembered game is more important than a pretty one.

---

## 8. Awards Are Personal, Not Absolute

Awards in MeepleGo:
- are retrospective
- are subjective
- often span years
- may be quirky, contradictory, or deeply personal

“Best of 2024” matters less than:
- “Games I Still Think About”
- “Games That Grew On Me”
- “Games I Rated Too Harshly”

Formal award systems are for **advanced users**, not the homepage.

---

## 9. Data Ethics & External Sources

MeepleGo respects external data sources and their ecosystems.

- External APIs (e.g., BGG) are used responsibly
- Data is cached, summarized, and transformed—not mirrored wholesale
- MeepleGo does not position itself as a replacement for source platforms

The value lies in **interpretation**, not replication.

---

## 10. The Tone of MeepleGo

MeepleGo’s voice is:
- thoughtful
- editorial
- curious
- never authoritative
- never hype-driven

It sounds like:
> “That’s interesting… I didn’t realize I felt that way.”

Not:
> “This game is objectively great.”

---

## 11. The Litmus Test

Before adding or changing a feature, ask:

1. Does this help a user understand *their* gaming life better?
2. Does it provide value with minimal effort?
3. Does it respect where the user is in their journey?
4. Does it avoid turning taste into competition?
5. Would this still make sense if BGG didn’t exist?

If the answer is “no” to more than one—rethink it.

---

## 12. One-Sentence Summary

> **MeepleGo is a personal board game journal that helps players reflect on their gaming life over time—surfacing patterns, rediscoveries, and insights that global rankings can’t.**
