# MeepleGo — Design Context

## Design Context

### Users
Board game enthusiasts ranging from casual players to serious collectors. The interface serves both: friendly and approachable on the surface (casual players can jump in and rate games immediately), but powerful and data-dense underneath for those who want to rank obsessively, build lists, and run awards seasons. Think Letterboxd or Goodreads — not a toy, not a spreadsheet.

### Brand Personality
**Precise. Warm. Earned.**
- Precise: Data and rankings are serious business. Numbers matter. The UI should feel trustworthy and credible.
- Warm: This is about joy — playing games with people you like. It shouldn't feel cold or corporate.
- Earned: The depth reveals itself through use. New users get a clean, welcoming experience. Power users discover richness.

### Aesthetic Direction
- **Feel**: Premium casual. Like a well-designed sports stats app or a music rating platform. Not startup SaaS, not gamer aesthetic.
- **Theme**: Light mode primary (dark mode infrastructure exists but disabled). Clean whites and the brand blue (#096EC2) as the dominant accent.
- **Typography**: Outfit for headings (distinctive, modern, slightly rounded), Inter for body. Fraunces/Archivo Black reserved for awards/prestige moments.
- **References**: Letterboxd, Goodreads, ESPN Stats, Apple Fitness+
- **Anti-references**: BoardGameGeek (dated, dense), generic Tailwind SaaS (gray cards, bland grids), game-y/gimmicky UI (dice icons, pixelated fonts, dark mode with neon glows)

### Design Principles
1. **Casual surface, powerful core** — The first thing a new user sees should feel inviting. Complexity earns its place through interaction, not upfront exposure.
2. **Data deserves hierarchy** — Ratings, rankings, and play counts are the product. Typography and spacing should make numbers readable and satisfying, not decorative.
3. **Brand blue is the signal** — #096EC2 is reserved for interactive elements and key data points. Don't dilute it with decorative use.
4. **No gimmicks** — No dice iconography, no "game night" visual tropes, no glassmorphism, no gradient text on headings. Premium, not playful.
5. **Mobile is a first-class citizen** — Many users will log plays and check rankings mid-game-night on their phones. The mobile experience must be fast and thumb-friendly, not a shrunk desktop.

### Accessibility
Best-effort approach: fix obvious contrast and keyboard issues, but not auditing to a formal WCAG standard. Interactive elements should have aria-labels. Focus indicators should be visible. Color should not be the only signal.
